How to Add Base to MetaMask Before You Bridge

How to add Base network to MetaMask: choose Base from the network list, use Chainlist, or enter verified mainnet details before bridging and confirm your address.

The Hashbeam Desk·Nov 27, 2026 · 22:00 UTC·4 min read

Base appears in MetaMask when you add Base mainnet through the wallet’s network list, Chainlist, or manual network settings. Base is EVM-compatible, so MetaMask can use it with network details such as its chain ID and RPC endpoint; the [Base documentation’s network details](https://docs.base.org/get-started/connect-to-base) confirms the mainnet values. To move supported crypto assets between Ethereum and Base after setup, the Base bridge is a cross-chain service for that transfer.

What to have ready

Start with MetaMask unlocked in the extension or app. You do not need to create another wallet account or expose your recovery phrase to add Base.

Adding a network changes which blockchain MetaMask connects to; it does not create a new account. Your Ethereum and Base account use the same wallet address, so you can check the address shown in MetaMask after switching networks. The assets shown at that address can differ by network: an Ethereum balance and a Base balance are separate.

Use Base mainnet for this setup. Its chain ID is 8453, its native gas currency is ETH, and its block explorer is Basescan. MetaMask’s [network support instructions](https://support.metamask.io/networks-and-sidechains/) explain how to add supported networks or enter custom network details.

Add Base to MetaMask

  1. Open MetaMask’s network selector and choose Add network. The wallet opens its network-add options.
  2. Look for Base in MetaMask’s built-in network list. If Base is listed, select it; this is the preferred method because you can add the network directly from MetaMask’s own list. Review the network information shown before approving.
  3. If Base is not in the built-in list, you can use Chainlist. Find Base mainnet there, confirm that the displayed chain ID is 8453, then use its add-network option and review the request in MetaMask. Chainlist can be a quick way to pass network details to the wallet, but the wallet’s approval prompt still deserves a careful check.
  4. For manual entry, choose the option to add a custom network and enter these Base mainnet values: Network name: Base; RPC URL: https://mainnet.base.org; Chain ID: 8453; Currency symbol: ETH; Block explorer URL: https://basescan.org. These are the values published in the [Base network documentation](https://docs.base.org/get-started/connect-to-base). MetaMask displays the completed details for review.
  5. Approve the request and switch to Base. MetaMask shows Base as the active network, with your existing wallet address. That confirms the network setup is complete.

Choose the method that fits

Use MetaMask’s built-in list when it includes Base. It is the simplest option and avoids copying network values yourself. If Base is absent, Chainlist is a convenient alternative for adding the network details through MetaMask.

Manual entry suits people who prefer to enter or verify each field themselves, including users who configure custom RPC endpoints. For this setup, use the published Base mainnet endpoint and compare every field against Base’s documentation before saving.

Network-add prompts can also arrive from websites. Treat an unfamiliar request cautiously: a malicious RPC can misrepresent network information or interfere with what MetaMask shows you. MetaMask says custom networks are not verified by the wallet, so check the chain ID and RPC against an authoritative source before approving. For Base mainnet, verify chain ID 8453; do not approve a request just because a site labels it “Base.”

Confirm Base before bridging

After switching, check that MetaMask identifies Base as the active network and displays the same account address you use on Ethereum. ETH is Base’s native gas currency, while assets on Base remain associated with that same address. Adding the network does not itself move funds between Ethereum and Base.

When you are ready to transfer supported assets across those networks, use the Base bridge for the cross-chain move. Choose Base in MetaMask when you want to interact with Base, and proceed once the active network and address match your intended destination.
